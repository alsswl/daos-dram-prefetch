# OFF와 ON 사이 저장 공간 회수 대기

OFF 1,684회 요청은 정상 완료했다. 서버 종료 후 해당 namespace의 KV 키
19,853개를 삭제했고, 다른 namespace의 54,225개 키가 그대로 보존된 것을 확인했다.

삭제 직후 DAOS NVMe 여유 공간은 361,359,433,728바이트였다. 다음 ON 조건의
보수적 저장량(422.27GiB)과 안전 여유 공간 검사에 걸려 ON 시작 전에 중단됐다.
이때 ON 디렉터리는 빈 상태였으며, 모델 서버나 요청은 시작하지 않았다.

잠시 후 읽기 전용 pool query에서 여유 공간이 원래의
777,707,020,288바이트로 회복되고 최소 타깃 여유가 45,869,703,168바이트인
것을 확인했다. 별도 강제 aggregation, 설정 변경, 다른 데이터 삭제는 하지 않았다.

내용이 없는 ON 준비 디렉터리만 제거하고 동일한 소스·설정·요청 목록으로
실행기를 재개한다. 완료된 OFF는 재실행하지 않는다. 시작 실패 기록은
service.log에 남아 있다. 이 대기는 HTTP 요청 측정 시간에 포함되지 않는다.
