# 실행 전 입력 검증 오류로 중단한 디렉터리

토크나이저의 `apply_chat_template` 반환 형식이 딕셔너리인 환경에서 길이를 토큰 수로 잘못 해석한 준비 오류를 발견했다. 서버 시작 대기 중 중단했으며 모델 요청은 보내지 않았다. 비교 결과로 사용하지 않는다.

실행기가 시작한 서버는 종료했다. 저장소 사전 왕복 검사는 성공했고 해당 임시 키는 검사 스크립트가 삭제했다.

수정: `return_dict=False` 지정과 정수 토큰 목록 검증, 총 입력 토큰 하한 검증, HTTP 응답의 실제 prompt_tokens 일치 검증.

유효한 새 실행 디렉터리: `../govreport_prefetch_20260928_v2`.
